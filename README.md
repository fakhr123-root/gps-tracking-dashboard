# مستخرج بيانات خرائط جوجل ثلاثي الأبعاد 3D (Google Maps 3D Extractor)

تطبيق متطور ومكتمل تم تصميمه لتلبية جميع متطلبات استخراج بيانات الأنشطة والشركات من خرائط جوجل بدقة 100% مع واجهة مستخدم ثلاثية الأبعاد تفاعلية وسلسة وبدون أي تعليق أو تجميد في الشاشة.

---

### ✨ المميزات الرئيسية للمشروع:

1. **حقول البحث المرنة (اختيارية بالكامل)**:
   - **نوع النشاط**: مثل (مطاعم، مقاهي، فنادق، عيادات، شركات عقارية، مكاتب محاماة...).
   - **موقع النشاط**: تحديد المدينة أو العنوان (الرياض، جدة، دبي، القاهرة، إلخ).
   - **الحي**: حقل اختياري لتحديد حي معين بدقة أكبر.
   - **نطاق البحث الجغرافي**: 
     - خيار سريع مخصص: **10 كم للمدن**.
     - خيار سريع مخصص: **16 كم للأحياء**.
     - شريط تمرير (Slider) للتحكم الدقيق من 1 كم وحتى 50 كم.
   - **عدد الشركات المطلوبة**: تحديد العدد (10، 20، 50، 100 حتى 200).
   - **دعم Google Places API Key**: إمكانية إدخال مفتاح Google Cloud API للحصول على بيانات Google الرسمية بنسبة 100%، أو ترك الحقل فارغاً للاستفادة من المحرك الذكي المباشر المجاني المدمج.

2. **المخرجات الدقيقة المستخرجة**:
   - 🏢 **الاسم**: اسم المنشأة أو الشركة الرسمي.
   - 🏙️ **المدينة**: المدينة التي تقع بها المنشأة.
   - 📍 **الحي**: الحي أو المنطقة بدقة.
   - 📞 **رقم التلفون**: رقم الهاتف الحقيقي للتواصل المباشر.
   - ⭐ **التقييم**: تقييم النجوم وإجمالي عدد المراجعات.
   - 📌 **اللوكيشن**: إحداثيات GPS ورابط خرائط جوجل المباشر للنقر والتنقل.
   - 🌐 **الموقع الإلكتروني**: رابط الويب الخاص بالنشاط.

3. **الأداء الفوري وبث النتائج لحظياً (Streaming بدون تعليق)**:
   - يعتمد على تقنية **Server-Sent Events (SSE)**، بحيث تظهر النتائج في الجدول وعلى الخريطة واحدة تلو الأخرى فور العثور عليها.
   - لا يوجد أي تجميد للواجهة أثناء البحث، مع شريط تقدم مباشر ونسب مئوية حية.

4. **الواجهة الرسومية ثلاثية الأبعاد (3D Visualization)**:
   - **مجسم كرة أرضية 3D (Three.js Earth Globe)**: تفاعلي بالكامل، يمكن تدويره بالماوس وتكبيره وتصغيره (Zoom & Orbit).
   - **دبابيس وإشعاعات ليزر 3D**: ترتفع على الكرة الأرضية فور استخراج كل منشأة عند إحداثياتها الجغرافية الفعلية.
   - **خريطة تفاعلية مدمجة**: إمكانية التبديل بين مجسم الكرة الأرضية 3D والخريطة التفاعلية الجغرافية بنقرة زر واحدة.
   - **تصميم سايبر-بانك نيون فاخر (Glassmorphism & 3D Tilt Cards)**.

5. **أدوات التصدير الفوري**:
   - 📗 **تصدير إلى ملف Excel (.xlsx)** بنقرة واحدة عبر محرك SheetJS.
   - 📄 **تصدير إلى CSV**.
   - 💻 **تصدير بصيغة JSON**.
   - 📋 **نسخ جماعي لجميع أرقام الهواتف** بضغطة زر لاستخدامها في الحملات الإعلانية ورسائل الواتساب.
